== ENHANCEMENTS
* link:https://github.com/pingidentity/pingcli-plugin-terraformer/commit/08fa4f1[08fa4f1] `resource/pingone_davinci_connector_instance` and `resource/pingone_davinci_flow`: Variable and resource references inside `jsonencode({...})` blobs in HCL output now render as bare Terraform traversals (`var.X`, `type.label.field`) instead of interpolation-only quoted strings (`"${var.X}"`). The deprecated interpolation form triggered tflint's `terraform_deprecated_interpolation` rule on exported modules. Re-exporting your configuration is recommended; the evaluated Terraform output is identical (bare traversals and interpolation-only strings are equivalent), and `.tf.json` output keeps its existing `"${jsonencode(...)}"` wrapping form. link:https://github.com/pingidentity/pingcli-plugin-terraformer/pull/159[#159]
* link:https://github.com/pingidentity/pingcli-plugin-terraformer/commit/76d13f1[76d13f1] `resource/pingone_davinci_variable`: Secret variables (`data_type = "secret"`) now export with a `value` block referencing a generated Terraform variable (`sensitive = true`) instead of being exported without a value. The generated variable's tfvars entry is empty — set it manually before applying; Terraform plan fails on an empty secret by design (the provider requires a non-empty `secret_string`), matching connector `clientSecret` handling. Non-secret variables are unchanged. Re-export your configuration to pick up the new blocks. link:https://github.com/pingidentity/pingcli-plugin-terraformer/pull/161[#161]
